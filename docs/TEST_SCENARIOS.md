# Тест-план і ручні сценарії Stargazing

| ID | Сценарій | Очікуваний результат |
| --- | --- | --- |
| TC-01 | Відкрити `/` | Каталог з товарами, цінами й категоріями |
| TC-02 | Фільтр «Обличчя» | Товари лише вибраної категорії |
| TC-03 | Знайти `Glow` | Є товар із відповідною назвою |
| TC-04 | Реєстрація з валідними даними | Створено акаунт, користувач увійшов |
| TC-05 | Реєстрація з повторним email | Валідація відмовляє у створенні |
| TC-06 | Вхід із неправильним паролем | Авторизацію відхилено |
| TC-07 | Додати 2 одиниці до кошика | Кошик містить 2 одиниці, сума правильна |
| TC-08 | Спробувати додати 999 одиниць | Дія відхилена |
| TC-09 | Оформлення з валідною адресою | Замовлення збережено, залишок зменшено |
| TC-10 | Замовити більше ніж на складі | Немає замовлення й списання товарів |
| TC-11 | Вибрати самовивіз | Вартість доставки 0 грн |
| TC-12 | Демо-оплата карткою | Лише тестовий статус `paid`, гроші не списуються |
| TC-13 | Додати відгук після входу | Відгук відображається для товару |
| TC-14 | Дублювати відгук одному товару | Валідація відхиляє дублікат |
| TC-15 | Надіслати повідомлення | Повідомлення з'являється у БД |
| TC-16 | Відкрити `/admin` як звичайний покупець | Повернення на каталог із попередженням |
| TC-17 | Створити товар адміністратором | Товар доступний у каталозі |
| TC-18 | Приховати товар адміністратором | Приховано в каталозі, історія замовлень незмінна |
| TC-19 | Відкрити чуже замовлення | `404`, дані не розкрито |
| TC-20 | Спробувати POST без CSRF-токена | Запит відхилено Rails (за стандартного захисту) |
| TC-21 | Додати товар до обраного | Лічильник змінюється, товар є на сторінці обраного |
| TC-22 | Повторно натиснути «Обране» | Товар вилучається зі списку, дублікат не створюється |
| TC-23 | Увійти на сайт із вузького екрана | Меню та картки товарів не виходять за межі екрана |
| TC-24 | Адмін скасовує замовлення «placed» | Статус `canceled`, кожна позиція повернута на склад |
| TC-25 | Адмін повторно скасовує замовлення | Відмова в переході, залишки не збільшено повторно |
| TC-26 | Адмін переводить замовлення в «shipped» | Новий статус збережено, залишки не змінюються |
| TC-27 | Адмін пробує «shipped» → «placed» | Відмова як для недопустимого переходу |
| TC-28 | Сторінки `/about` і `/delivery` | Відображається контент, посилання в навігації працюють |

**Статус:** підготовлені сценарії; фактичний браузерний прогін має бути виконаний після встановлення gems і запуску Rails у середовищі студента. Автоматизовані Minitest розміщені в `test/`.
